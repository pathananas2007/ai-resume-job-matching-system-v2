# Quick Start Guide - Backend SetupFollow these steps exactly to start the backend server:## Step 1: Open Terminal in Backend Directory```powershellcd backend```## Step 2: Create Virtual Environment (First Time Only)```powershellpython -m venv venv```Wait for it to complete (takes 30-60 seconds).## Step 3: Activate Virtual Environment```powershellvenv\Scripts\activate```You should see `(venv)` appear at the start of your command prompt.## Step 4: Install Dependencies (First Time Only)```powershellpip install -r requirements.txt```This will take 1-2 minutes to install all packages.## Step 5: Add Your Gemini API Key1. Open the file: `backend/.env`2. Find line 4: `GEMINI_API_KEY=your_gemini_api_key_here`3. Replace `your_gemini_api_key_here` with your actual API key4. Save the fileExample:```envGEMINI_API_KEY=AIzaSyC7raMyxqewcm0rAUtDZoh6TJnjwLVV6tY```## Step 6: Start the Server```powershellpython main.py```## Γ£à Success!You should see output like:```INFO:     Started server processINFO:     Waiting for application startup.INFO:     Application startup complete.INFO:     Uvicorn running on http://0.0.0.0:8000```## ≡ƒîÉ Access the Backend- **API Root:** http://localhost:8000- **API Docs:** http://localhost:8000/docs- **Health Check:** http://localhost:8000/health## ≡ƒ¢æ Stop the ServerPress `Ctrl + C` in the terminal## ≡ƒô¥ Next TimeAfter the first setup, you only need to:1.
